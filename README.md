# A 股龙头战法复盘看板

静态 GitHub Pages 页面。数据由 GitHub Actions 在工作日北京时间 16:40 后抓取公开收盘复盘页面并写入 `data/market.json`。

## 本地预览

直接打开 `index.html` 即可查看最后一次已提交的数据。更新数据：

```bash
python scripts/update_market.py
```

## 数据说明

- 市场与连板数据来自连板网公开收盘复盘页；高度趋势保存最近 22 个交易日，并标注每日最高板全部股票名称。
- 高度压力线取当前交易日前 5 个交易日最高板的最大值，仅描述历史结构。
- 沪深 300 滚动市盈率来自中证指数有限公司公开接口；高低估线为 2018 年至今的日度均值 ± 1 个总体标准差。
- 连板策略回测采用“最高板 4–7 板且封板率≥70%”的市场环境筛选，按下一交易日最高板是否不低于当日最高板统计高度延续事件率；它不是个股交易收益率。
- 工作日北京时间 17:00 前固定使用上一已收盘交易日，避免将盘中滚动快照计入复盘或回测。

页面仅用于研究和复盘，不构成投资建议。数据源页面可能在收盘后修订；Actions 会保存每次运行时的快照。
